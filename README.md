# SRS Public School Website

Responsive static school website inspired by the structure of a traditional school site, with original branding and content for SRS Public School.

## Run Locally

Open `index.html` directly in a browser, or run the included local server:

```powershell
node server.mjs
```

Then visit `http://localhost:5173`.

## Files

- `index.html` - page content and semantic structure
- `styles.css` - responsive UI, layout, cards, forms and mobile menu styles
- `script.js` - mobile navigation, demo form alerts, counters and active navigation
